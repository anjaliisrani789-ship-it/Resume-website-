# Personal Resume Website

This is a beginner-friendly personal resume/portfolio website built with HTML and CSS.

## Files
- `index.html` — website structure and content
- `style.css` — colours, typography, layout, navigation, cards and responsive styling

## Before publishing
1. Replace `Your Name` with your name in `index.html`.
2. Replace `YN` in the monogram with your initials.
3. Replace `your.email@example.com` with your real email address.
4. Check every section and edit any details that you do not want to display.

## Run locally
Open `index.html` in a web browser. Keep `index.html` and `style.css` in the same folder.

## CSS concepts demonstrated
- Element, class and ID selectors
- Font families, sizes, weights and colours
- Flexbox and CSS Grid (`display`)
- Sticky navigation and positioning
- Spacing, borders, shadows and alignment
- Responsive media queries for smaller screens
